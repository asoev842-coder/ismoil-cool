# Свадебное приглашение

## Публикация
1. В настройках репозитория открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку **main** и папку **/(root)**, нажми **Save**.
4. Репозиторий должен быть публичным для бесплатной публикации GitHub Pages.

## Персональные ссылки
Ссылки используют параметр `?g=код`, например `?g=a7K2m`. Имена хранятся в `guest-data.js`.
Открой `guest-admin.html`, добавь гостей и скачай новый `guest-data.js`. Затем замени этим файлом старый в корне репозитория через **Add file → Upload files**.

Содержимое репозитория публично. Не храните здесь конфиденциальные данные.
