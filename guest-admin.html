Персональные ссылки для гостей

Меняй имена, добавляй гостей и нажимай «Сохранить на GitHub». Файл обновится автоматически, вручную загружать его не нужно.

1. Доступ для сохранения

Нужен GitHub Personal Access Token с доступом только к этому репозиторию и правом Contents: Read and write. Токен используется только в этой вкладке и не сохраняется на устройстве. Не отправляй его никому.

Создай токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Выбери репозиторий ismoil-cool и разрешение Contents: Read and write.
